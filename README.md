# Shambles

> Корпоративный сайт-заглушка ни о чём. Форма — аккуратный шаблон нулевых с рекламой, содержание — абстрактный корпоративный новояз, генерируемый на сервере.

## О проекте

Этот проект — сатира на современный веб. Он выглядит как максимально агрессивный, неудобный и перегруженный рекламой сайт из 2005 года (с cookie-баннерами, бегущими строками и убегающими кнопками).

Однако под капотом используется исключительно современный стек, строгая типизация, тесты и оптимизация производительности. Цель проекта — доказать, что даже самый ужасный UX можно реализовать технически безупречно и доступно.

## Технологический стек

- **Framework:** Next.js 16 (App Router, Turbopack)
- **UI:** React 19, TypeScript (strict mode)
- **Runtime:** Edge Runtime для API роутов
- **Testing:** Vitest (26+ тестов логики и грамматики)
- **Морфология:** Собственный генератор абстрактных фраз с согласованием русских существительных, прилагательных и глаголов по родам, числам и падежам.

## Сатирические фичи

- **Генератор бессмыслицы:** SSR-совместимый генератор корпоративного новояза. Один и тот же URL всегда выдаёт одинаковый текст.
- **Убегающая кнопка:** Кнопка «Закрыть» в модалке убегает от курсора. Но она доступна с клавиатуры и сдаётся, если её загнать в угол.
- **Cookie-эскалация:** 5 уровней баннера cookie. Если отказываться — баннер становится всё более наглым, а на 5 уровне кнопка «Отклонить» исчезает.
- **Ленивая реклама:** SVG-баннеры подгружаются через Edge API только при скролле (IntersectionObserver).
- **Сброс таймера:** Таймер «горячего предложения» сбрасывается на 10 минут при обновлении страницы.
